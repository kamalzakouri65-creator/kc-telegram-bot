# KC Nasdaq ORB V1

**اختبار تاريخي فقط.** لا تداول ولا اتصال بأي حساب. بيانات QQQ (يتبع Nasdaq 100) من Twelve Data. مشروع مستقل لا يلمس بوت الذهب.

## القواعد (ثابتة في `src/config.js`)
- **النطاق:** أعلى وأدنى سعر في أول 30 دقيقة بعد افتتاح نيويورك (09:30، بتوقيت نيويورك).
- **الدخول:** إغلاق شمعة 15 دقيقة فوق النطاق (شراء) أو تحته (بيع)، حتى 11:30. أول اختراق فقط، وصفقة واحدة في اليوم.
- **الوقف:** منتصف النطاق. **الهدف:** 2R. **الخروج:** عند إغلاق السوق إن لم يُضرب الوقف أو الهدف.
- **التكاليف:** سبريد US100 التقديري عند XM (~0.007% من السعر).
- **النجاح:** 100 صفقة على الأقل، PF ≥ 1.2، وآخر 30% من الأيام رابحة.

## التشغيل
```bash
cd kc-nasdaq-orb
npm test
npm run fetch-data   # سنتان من شموع 15 دقيقة (~3 طلبات، يستعمل مفتاح بوت الذهب)
npm run backtest     # التقرير في logs/report.txt وكل الصفقات في logs/trades.csv
```
