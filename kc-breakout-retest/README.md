# KC Breakout + Retest V1

**اختبار تاريخي فقط.** لا يوجد أي تداول حقيقي أو تجريبي، ولا أي مفاتيح Binance. البيانات من `data-api.binance.vision` (بيانات السوق العامة فقط). مشروع مستقل لا يلمس أي مشروع آخر في المستودع.

## القواعد (ثابتة في `src/config.js`)

- **المقاومة H1:** قمتان مستقلتان على الأقل (قمة = أعلى من شمعتين قبلها وشمعتين بعدها)، من آخر 200 شمعة، وبينهما ابتعاد 0.5×ATR. عرض المنطقة 0.2×ATR، والمستوى متوسط القمم.
- **الاختراق H1:** إغلاق فوق المنطقة بـ 0.1×ATR، وجسم ≥ 60% من المدى، وحجم ≥ 1.5× متوسط آخر 20 شمعة مكتملة.
- **إعادة الاختبار M15:** خلال 12 ساعة. الإلغاء عند إغلاق تحت منتصف المنطقة.
- **الدخول:** شمعة تأكيد صاعدة (جسم ≥ 50%)، ثم اختراق قمتها خلال 4 شموع M15.
- **الوقف:** تحت آخر قاع M15 مؤكد بـ 0.2×ATR(M15). **الهدف:** 1:2 ثابت، بدون إغلاق جزئي أو وقف متحرك.
- **المخاطرة:** 1% من الرصيد الحالي، ورصيد ابتدائي 50$. صفقتان يومياً كحد أقصى، والتوقف بعد خسارتين متتاليتين، وصفقة نشطة واحدة.
- **التكاليف:** رسوم 0.1% لكل جهة (ومقارنة بـ 0.075%)، وانزلاق 0.05% على الدخول والخروج.

قرارات التفسير حيث كانت المواصفات غير محددة موجودة في `DECISIONS` داخل `src/config.js`، ومطبوعة في التقرير.

## التشغيل

```bash
cd kc-breakout-retest
npm test             # اختبارات القواعد ومنع النظر للمستقبل وعدم وجود كود تداول
npm run fetch-data   # آخر سنتين H1 و M15 لـ BTC و ETH (مع فحص الجودة)
npm run backtest     # التقرير
```

المخرجات في `logs/`: `report.txt` (التقرير)، و`trades.csv` (سجل كامل لكل صفقة)، و`equity.csv` (منحنى رأس المال)، و`skipped.csv` (الفرص المتخطاة وأسبابها).
