# بوت إشارات الذهب والفوركس 📊

بوت تيليغرام يراقب الذهب (XAU/USD) وأزواج الفوركس، ويرسل إشارات شراء وبيع مبنية على التحليل الفني، مع وقف خسارة وهدفين.

> ⚠️ **تنبيه:** الإشارات آلية ولأغراض التحليل والتعلّم فقط، وليست نصيحة مالية. التداول بالرافعة ينطوي على مخاطرة عالية بخسارة رأس المال. جرّب الإشارات على حساب تجريبي أولاً.

## الاستراتيجية

تُحسب الإشارة على آخر شمعة **مغلقة** (الإطار الافتراضي ساعة):

| الشرط | شراء 🟢 | بيع 🔴 |
|---|---|---|
| الاتجاه | EMA50 فوق EMA200 والسعر فوق EMA50 | EMA50 تحت EMA200 والسعر تحت EMA50 |
| الزخم | MACD يقطع خط الإشارة صعوداً | MACD يقطع خط الإشارة هبوطاً |
| التصفية | RSI بين 50 و 70 | RSI بين 30 و 50 |

- **وقف الخسارة:** 1.5 × ATR(14)
- **الهدف 1:** 1.5 × المخاطرة، **الهدف 2:** 3 × المخاطرة

## التشغيل

1. أنشئ بوتاً عبر [@BotFather](https://t.me/BotFather) وخذ التوكن (يمكنك استخدام نفس بوت `kc-telegram-bot`).
2. سجّل مجاناً في [Twelve Data](https://twelvedata.com) وخذ مفتاح API.
3. انسخ `.env.example` إلى `.env` واملأ القيم.
4. شغّل:

```bash
npm install
npm start
```

## الأوامر في تيليغرام

- `/start`: تعريف بالبوت
- `/status`: حالة كل زوج الآن (السعر، الاتجاه، RSI، MACD)
- `/signal`: فحص فوري للإشارات
- `/results`: نتائج الإشارات السابقة: كم منها ربح وكم خسر، والمجموع بوحدة R

البوت يتابع كل إشارة يرسلها، ويرسل لك رسالة عندما تصل إلى **الهدف 1** 🎯 أو **الهدف 2** 🏆 أو **وقف الخسارة** ❌، حتى لو لم تدخل الصفقة. الإشارات تُحفظ في `data/trades.json` فلا تضيع عند إعادة التشغيل.

## الإعدادات (في `.env`)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `SYMBOLS` | `XAU/USD,EUR/USD,GBP/USD,USD/JPY` | الأزواج المراقبة |
| `INTERVAL` | `1h` | إطار الشموع (`15min`, `1h`, `4h`, `1day`)، ويمكن أكثر من إطار مثل `1h,4h` |
| `CHECK_EVERY_MINUTES` | `15` | كل كم دقيقة يفحص البوت |
| `STRATEGY` | `ema-macd` | الاستراتيجية: `ema-macd` أو `order-block` |

الخطة المجانية في Twelve Data تسمح بـ 800 طلب يومياً و 8 في الدقيقة. الإعداد الافتراضي (4 أزواج كل 15 دقيقة) يستهلك نحو 384 طلباً يومياً.

## 🧱 استراتيجية Order Block (اختيارية)

بدل الاستراتيجية الافتراضية، يمكن تشغيل استراتيجية **Order Block** بوضع `STRATEGY=order-block` في `.env`:

- **البلوك الصاعد:** آخر شمعة هابطة قبل اندفاع صاعد كسر آخر قمة (Break of Structure)، والاندفاع لا يقل عن 1.5 × ATR. والبلوك الهابط عكسه.
- **الإشارة:** عند **أول** عودة للسعر إلى البلوك، بشرط أن تغلق الشمعة **رافضة** له (صاعدة فوق منتصفه للشراء، وهابطة تحت منتصفه للبيع). البلوك يُستهلك بعد أول لمسة.
- **وقف الخسارة:** خلف البلوك بهامش 0.25 × ATR. **الهدفان:** 2 × و 3 × المخاطرة.
- رسالة الإشارة تعرض حدود البلوك 🧱.

## 📊 الاختبار التاريخي (Backtest)

يجرّب الاستراتيجيتين على آخر 5000 شمعة ويقارن النتائج:

```bash
npm run backtest -- XAU/USD 1h 0.35
```

الرقم الأخير اختياري، وهو **السبريد** بوحدة السعر (مثلاً `0.35` للذهب، و `0.0001` لـ EUR/USD)، ويُخصم من كل صفقة.

النتائج بوحدة **R**، أي المبلغ الذي تخاطر به في كل صفقة. كل صفقة تُقسم نصفين (الهدف 1 والهدف 2)، وإذا لمست الشمعة الوقف والهدف معاً يُحسب الوقف. العمولة غير محسوبة. كل تشغيل يستهلك طلباً واحداً من رصيد Twelve Data.

## 🤖 التداول الآلي على MetaTrader 5

يمكن للبوت فتح الصفقات تلقائياً على حسابك في MT5 عند كل إشارة جديدة، عبر خدمة [MetaApi](https://metaapi.cloud) السحابية، فلا تحتاج لتشغيل MT5 على حاسوب. وتتابع الصفقات من تطبيق MetaTrader 5 على هاتفك.

### الإعداد

1. افتح **حساباً تجريبياً (Demo)** في MT5 من تطبيق الهاتف أو من موقع وسيطك، واحفظ رقم الحساب وكلمة المرور واسم السيرفر.
2. سجّل في [MetaApi](https://app.metaapi.cloud)، ثم أضف حسابك من **Accounts → Add account** (المنصة mt5، مع رقم الحساب وكلمة المرور والسيرفر).
3. انسخ **Account ID** من صفحة الحساب، و **API token** من صفحة **API access**.
4. أضف القيم في `.env`:

```env
METAAPI_TOKEN=...
METAAPI_ACCOUNT_ID=...
AUTO_TRADE=true
```

5. أعد تشغيل البوت، وأرسل `/account` للتأكد من الاتصال.

### إدارة المخاطرة

- **حجم اللوت يُحسب تلقائياً** بحيث لا تتجاوز الخسارة عند وقف الخسارة `RISK_PERCENT` من الرصيد (الافتراضي 1%). إذا كان أقل حجم مسموح يتجاوز هذه المخاطرة، لا تُفتح الصفقة.
- الحجم يُقسم على **صفقتين**: نصف عند الهدف 1 ونصف عند الهدف 2، وكلاهما بنفس وقف الخسارة.
- صفقة واحدة فقط لكل رمز، وبحد أقصى `MAX_OPEN_POSITIONS` صفقات مفتوحة.
- **الحساب الحقيقي مرفوض افتراضياً.** لا يُسمح به إلا بوضع `ALLOW_REAL_TRADING=true`، ولا يُنصح بذلك قبل تجربة طويلة على الحساب التجريبي.
- الأمر `/signal` يعرض الإشارات فقط ولا يفتح صفقات. التنفيذ يحدث في الفحص الدوري فقط.

### أوامر التداول (لصاحب البوت فقط، أي `TELEGRAM_CHAT_ID`)

- `/account`: الرصيد والسيولة والصفقات المفتوحة
- `/autotrade on` / `/autotrade off`: تشغيل أو إيقاف التنفيذ الآلي فوراً

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `METAAPI_TOKEN` | | توكن MetaApi |
| `METAAPI_ACCOUNT_ID` | | معرّف الحساب في MetaApi |
| `METAAPI_REGION` | `new-york` | منطقة الحساب في MetaApi (`london`, `singapore`...) |
| `MT_SYMBOL_SUFFIX` | فارغ | لاحقة الرموز عند وسيطك، مثل `m` في `XAUUSDm` |
| `MT_SYMBOL_MAP` | فارغ | أسماء مختلفة عند وسيطك، مثل `XAU/USD=GOLD` في XM |
| `AUTO_TRADE` | `false` | تشغيل التنفيذ الآلي عند بدء البوت |
| `RISK_PERCENT` | `1` | نسبة المخاطرة من الرصيد لكل صفقة |
| `MAX_OPEN_POSITIONS` | `3` | أقصى عدد للصفقات المفتوحة |
| `ALLOW_REAL_TRADING` | `false` | السماح بالحساب الحقيقي |

> الحساب يجب أن تكون عملته **USD** لحساب حجم اللوت للأزواج المدعومة (XAU/USD, EUR/USD, GBP/USD, USD/JPY).

### تشغيل البوت من الهاتف (أندرويد)

البوت يحتاج أن يعمل باستمرار. يمكنك تشغيله على هاتف أندرويد عبر تطبيق [Termux](https://f-droid.org/packages/com.termux/):

```bash
pkg install nodejs git
git clone https://github.com/kamalzakouri65-creator/kc-telegram-bot
cd kc-telegram-bot/gold-forex-signals-bot
cp .env.example .env && nano .env
npm install && npm start
```

اترك Termux يعمل في الخلفية (فعّل **Acquire wakelock** من إشعار Termux). وللتشغيل الدائم دون إبقاء الهاتف متصلاً، الأفضل استضافته على سيرفر مثل Railway أو Render أو VPS.
