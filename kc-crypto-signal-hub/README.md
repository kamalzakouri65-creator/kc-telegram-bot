# KC Crypto Signal Hub V1

نظام **إشارات شراء فقط** لـ **BTC/USDT** و **ETH/USDT** على Binance Spot، يرسلها إلى تيليغرام.

> ⛔ **لا يوجد أي تنفيذ صفقات.** النظام لا يضع ولا يلغي ولا يعدّل أي طلب، ولا يحتوي أي سحب، ولا يطلب ولا يقبل مفاتيح Binance. يقرأ فقط بيانات السوق العامة من `data-api.binance.vision`. كل إشارة معلوماتية والقرار والتأكيد لك.

مشروع مستقل تماماً عن بوت الذهب (`../gold-forex-signals-bot`)، ولا يشترك معه في أي ملف.

## الاستراتيجية (شراء فقط)

| الإطار | الدور |
|---|---|
| **H1** | السعر فوق **EMA200** والهيكل صاعد (آخر قمتين وآخر قاعين متصاعدة HH/HL) |
| **M15** | سحب سيولة تحت قاع مؤكد مع إغلاق فوقه ← كسر هيكل صاعد (BOS أو CHoCH) ← **Order Block** مع اندفاع (جسم ≥ 1×ATR14) ← أول عودة للسعر إلى البلوك. FVG يرفع الثقة |
| **M5** | خلال 3 شموع M15 بعد العودة: **ابتلاع صاعد** أو **اختراق** أعلى 3 شموع، مع حجم أكبر من **SMA20** للحجم |

- **الوقف:** تحت قاع سحب السيولة بهامش 0.1×ATR. لا يُوسّع أبداً.
- **الهدف:** بحيث يكون الربح **الصافي** = 2 × الخسارة **الصافية** (بعد الرسوم والانزلاق).
- **منطقة الدخول:** من سعر التأكيد حتى +0.15%. تنتهي الإشارة إن لم يدخلها السعر خلال 3 شموع M15.
- **نقل الوقف للتعادل بعد 1R:** اختياري (`breakEven` في `src/config.js`)، ومتوقف افتراضياً.
- الشموع المغلقة فقط، ولا إعادة رسم ولا نظر للمستقبل (مثبت بالاختبارات).

## إدارة المخاطرة

رصيد 50$، ومخاطرة **0.5%** (0.25$) لكل إشارة شاملة الرسوم، وحد خسارة يومي **1%**، وصفقتان كحد أقصى يومياً، والتوقف بقية اليوم بعد خسارتين متتاليتين، وإشارة نشطة واحدة فقط للحساب كله. الحجم يُقرّب للأسفل لوحدة Binance، وتُرفض الإشارة (مع ذكر السبب) إذا كانت أقل من الحد الأدنى للطلب (5$)، أو أكبر من الرصيد، أو إذا كانت الرسوم أكثر من 35% من المخاطرة.

## الأوامر (Termux)

```bash
cd kc-crypto-signal-hub
npm test                 # الاختبارات (بدون إنترنت)
npm run fetch-data       # تحميل 12 شهراً من بيانات Binance العامة (بضع دقائق، حوالي 25MB)
npm run backtest         # الاختبار التاريخي، والتقرير يُحفظ في logs/backtest-report.txt
npm run diagnose         # تحليل أسباب الفشل لكل صفقة (logs/diagnosis.txt)
npm run fetch-oos        # تحميل سنتين لم تُستعملا (2023-10 إلى 2025-10) في مجلد منفصل
npm run oos-test         # اختبار الفرضية المسجلة مسبقاً في src/backtest/oos.js، مرة واحدة
```

`npm run fetch-data -- 180` يحمّل 180 يوماً فقط.

## المراقبة الحية (متوقفة حتى موافقتك)

لا تعمل إلا بشرطين معاً: `LIVE_MONITORING_APPROVED=yes` في `.env`، وإضافة `--i-approve-live-monitoring` للأمر:

```bash
cp .env.example .env     # ثم املأ TELEGRAM_BOT_TOKEN و TELEGRAM_CHAT_ID
npm run monitor -- --i-approve-live-monitoring
```

تفحص كل دقيقة، وترسل: الإشارات، والإعدادات المرفوضة مع أسبابها، وانتهاء الإشارات، ونتيجة كل إشارة (متابعة افتراضية)، وملخصاً يومياً، وتقريراً أسبوعياً، والأخطاء. لا تُرسل نفس الرسالة مرتين.

**تنبيهات TradingView (اختياري):** `--webhook-port=8080` يشغّل خادماً يستقبل `POST /webhook` بجسم `{"secret": "...", "pair": "BTCUSDT"}`، والتنبيه يطلب فحصاً فورياً فقط ولا يحمل أي أمر. يحتاج عنواناً عاماً على الإنترنت، ولا يعمل من الهاتف مباشرة.
